# signalcraft-web — Next.js dashboard (§19, §31).

Pages: Overview, Trending For You, Content Opportunities, Create, Content
Library, Analytics, Content Calendar, AI Insights, Agent. All data comes from
the FastAPI backend (`NEXT_PUBLIC_API_URL`); no secrets live here (§24).

```bash
npm install
npm run dev      # http://localhost:3001 (API on :8001)
npm run build && npm start
```
